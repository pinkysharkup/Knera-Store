# Knera Store

Knera Store is a modern, responsive e-commerce storefront built using **Next.js**, **TypeScript**, and **Tailwind CSS**.
The project focuses on clean UI, smooth user experience, and scalable component architecture.

---

# 🚀 Live Features

* Modern E-commerce UI
* Responsive Design (Mobile + Desktop)
* Dynamic Hero Sections
* Product Slider
* Categories Grid
* Shopping Cart System
* Login Modal
* Currency Dropdown
* Testimonials Section
* Blog / Journal Section
* Instagram Story Section

---

# 🛠 Tech Stack

* Next.js 14 (App Router)
* TypeScript
* Tailwind CSS
* React Context API
* Lucide Icons

# ⚡ Installation

Clone the repository:

```bash
git clone https://github.com/pinkysharkup/Knera-Store.git
```

Go to project folder:

```bash
cd Knera-Store
```

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```

Open in browser:

```
http://localhost:3000
```
